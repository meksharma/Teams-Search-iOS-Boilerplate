# Teams Search

A SwiftUI design and development POC for Microsoft Teams mobile search.

## Watch the demos

**[Zero-input search](./Demos/01-zero-input-search.mp4)** · **[Query and filters](./Demos/02-query-and-filters.mp4)**

The prototype covers gently revealed suggestions, partial-query matching, highlighted terms, mixed results, and People, Messages, Files, and Channels filters.

## Run in Xcode

```bash
git clone https://github.com/meksharma/Teams-Search-iOS-Boilerplate.git
cd Teams-Search-iOS-Boilerplate
open TeamsSearchBoilerplate.xcodeproj
```

Run `TeamsSearchBoilerplate` for the interactive flow or `TeamsSearchPortfolioIntro` for the automated portfolio sequence. Requires Xcode 27 or later and iOS 17 or later.
